# 🎮 Bubble Blast Pro

A strategic bubble-popping game inspired by **Balatro**, designed for mobile browsers.

🫧 Tap to pop connected bubbles of the same color  
💣 Bombs will clear surrounding bubbles  
🌈 Rainbow bubbles chain-react intelligently  
🎯 Reach the score target to level up  
🎰 Pull the lever when SPIN is ready to refresh the board!
